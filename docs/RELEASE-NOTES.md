More Platforms for Mad Games Tycoon 2 — 1.2.0

- Choose 4–16 platforms per project when creating a campaign.
- Select extra platforms in the original development screen, with scrolling.
- Campaign-specific limit and persistence for extra platforms.
- Mod-specific interface text is in Portuguese.

Requires BepInEx 5 Windows x64; tested with 5.4.23.3 and Steam build 20855306.
Download `MorePlatforms-1.2.0.zip` to install. The source archive is for developers.

Single-player only. Back up saves before use. Do not save an extended-platform
campaign without the mod installed. Legacy displays and some specialized
mechanics retain four-platform behavior.

Build, persistence-format tests, patch compatibility checks and isolated Unity UI
tests passed locally. A full development/release/save/reload gameplay test remains
pending. Treat this initial distribution as a testing release.
